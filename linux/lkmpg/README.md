# The Linux Kernel Module Programming Guide

> GitHub link: https://github.com/sysprog21/lkmpg

This project (lkmpg) keeps the Linux Kernel Module Programming Guide up to date, with working examples for recent 5.x
and 6.x kernel versions.
This guide has been around since 2001 and most copies of it on the web only describe the old 2.6.x kernels.
